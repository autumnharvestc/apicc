# 自托管在线执行代理

桌面客户端负责项目接口、环境、数据、认证和测试定义。管理台负责代理基础设施、工作区授权、项目分配、项目关联和执行策略。执行位置与环境分别选择；指定代理不可用时不会自动改到本机或其他代理。

首版独立代理为 Linux 容器，使用 Node 22.19.0 / V8 12.4.254.21-node.29；Windows 桌面使用 Electron 44.1.0 内嵌 Node 24.19.0 / V8 15.2.124.18-electron.0。运行准入同时校验精确 Node/V8、脚本 API 身份、Core 构建身份和能力。未知组合先拒绝；更换镜像大版本、Electron 或依赖后必须重新取得同 Core 语义证据。当前候选的最终产物摘要与验收状态见阶段交付报告，不能拿历史包代替。

支持单接口调试、测试套件、v2 工作流及现有 HTTP 用例/工作流压测。只有真正无脚本的单请求调试复用常驻 worker，带脚本调试、套件和工作流各占完整独立任务进程。压测使用独占进程：workerCount=1 占 1 个执行进程，N>1 占 1 个协调器加 N 个 worker，不按请求或节点创建进程。上述路径共用总任务槽；压测另受压测任务、进程、VU、请求并发、RPS 和数值预算约束。降低额度等待已有任务排空，不终止旧任务。显式 Cookie 会话绑定服务、项目、提交者和代理，普通取消只影响本次调用。worker 整代退出会如实标记受影响调用中断。

受信同步脚本沿用现有 Core 的 `pm.variables`、`pm.environment`、`pm.request`、`pm.response` 和 `pm.assert`。脚本按目标及生命周期完整闭包中的实际版本批准或显式信任整个项目；版本变更使单版本批准失效，无脚本任务使用真正的 no-script registry。脚本可能接触本次获授权的认证材料，因此批准应由项目管理员完成。这里使用现有 `node:vm` 语义，不承诺隔离恶意代码；DEF-001 未恢复，不包含 WASM/QuickJS、任意宿主 API、自动 npm/插件加载、跨代理压测、定时执行、长连接或 Windows 代理安装器。

项目凭据在后端使用独立 32 字节原始主密钥加密；主密钥不在数据库或镜像里。个人临时凭据可仅保存在本机，不自动上传；含仅本机材料时指定代理先拒绝。任务固定快照、凭据版本、附件版本和脚本依赖，准备声明由代理调用同 Core 重算，后端许可后才执行。Java 控制服务不复制 Core 执行算法，也不启动 Node 准备服务。

配置时长单位为毫秒、存储预算为字节、子进程堆上限为 MiB。配置保存版本与已应用版本分开；影响旧 worker 的项等待排空或重启，页面显示原因和待应用字段。部署默认经真实 Properties/环境绑定后记录持久检查点，重启改变继承值时推进版本并重新下发；显式代理覆盖仍优先。仅收到配置不等于已经应用。

压测新增额度由管理台对应层级管理员维护；工作区/项目只收紧继承策略。客户端保存纯 Core 计划并选择本次位置、环境、worker 数和目标确认，不管理节点额度。默认值和单位如下：

| 字段 | 默认 | 范围及含义 |
| --- | --- | --- |
| agent.maxConcurrentStressJobs | 1 | 0 到 maxConcurrentJobs；0 停止接新压测 |
| agent.maxStressProcesses | 5 | 正安全整数；协调器和 worker 合计进程 |
| agent.maxStressVus | 100 | 1–1000 VU；节点预留总额 |
| agent.maxStressRequestConcurrency | 100 | 1–1000 请求；节点并发预留总额 |
| agent.maxStressRps | 1000 | 正有限数，请求/秒；节点预留总额 |
| agent.maxStressMetricMemoryBytes | 335544320 | 正安全整数，字节；默认 320 MiB 数值预算总额 |
| policy.maxStressWorkers | 4 | 正整数；每任务 worker 上限 |
| policy.maxStressVus | 1000 | 1–1000 VU；每任务上限 |
| policy.maxStressRequestConcurrency | 1000 | 1–1000 请求；每任务上限 |
| policy.maxStressRps | 1000 | 正有限数，请求/秒；每任务上限 |
| policy.stressMetricMemoryBytes | 67108864 | 1048576–67108864 字节/执行进程；默认 64 MiB |
| policy.stressEvidenceMaxSamples | 20 | 1–20 条/最终报告，非每 worker 独立额度 |
| agent.stressProgressIntervalMs | 1000 | 250–60000 毫秒；累计进度发布间隔 |
| run.stress.workerCount | 1 | 正整数；同时受 maxVus、策略和节点进程容量限制 |
| run.stress.confirmedTargetOrigins | 空数组 | 本次 intent、位置、环境及快照的 HTTP(S) origin 确认 |

每任务预留 1 个总任务槽、1 个压测任务槽、上述执行进程数、plan.maxVus、编译后的请求并发、有限有效 RPS，以及进程数 × 每进程数值预算。不能用任务槽代替进程数，不能把到达率（逻辑迭代启动/秒）当请求 RPS。显式超额拒绝；合法任务因其他任务占用而等待时不启动执行进程，也不自动降低负载。CPU、RSS 与连接数是观测，数值预算不是整机内存硬隔离；部署仍需独立设置 CPU/内存及子进程堆限制。

压测复用 Core 的常量 VU、常量到达率和阶段负载 A。任务固定目标、环境、材料、运行设置以及 setup/vuSetup/vuTeardown/teardown；计划保存后再修改不改变在途快照。localhost/127.0.0.1 指所选执行位置自身。停止只作用于所选任务，确认所有执行后代退出才释放资源；期限或强制退出不保证 teardown 业务请求完成。桌面关窗后已开始的代理任务按本地期限继续，重开只查历史，不重新发送。

报告分别呈现逻辑迭代、真实请求及失败、执行/指标/负载完整性和归档状态。工作流恢复后逻辑成功仍保留原请求失败；零请求、缺数据或未知时钟不会自动变成通过。私有标记联合屏障未完成时压制富证据并明确限制。在线报告与 HTML 使用同一安全投影；HTML 默认中文、可切 English，原始数据默认折叠。基线显式选择并显示六项 Core 指标、执行条件差异及环境定义未比较限制。

控制链仅接受规范 HTTPS `/api/v1` 地址；`apicc.execution.control-base-url` 是部署身份，不从 Host/Forwarded 头推断。私有 CA 文件局部挂载给代理并保留证书与 SAN 校验。参见 [Compose 示例](../deploy/runner-agent/README.md)，其中主密钥、服务证书、代理 CA、身份 token、控制数据卷和代理账本卷分别管理。

代理使用 Node 内置 SQLite 持久账本和 owner/child lease。控制断线后已开始任务继续至本地期限；代理重启不会自动续跑或重跑业务，结果按原字节重传并等待归档确认。逻辑结论、真实请求事实、执行资源释放和结果归档分别显示。SQLite 的实验性告警如实保留；首次部署应配置足够磁盘与结果预留，本文不宣称已做 OOM/磁盘填满或全天运行专项。

开始前批准、权限或额度发生变化时，控制服务可持久返回明确的启动拒绝及安全原因；代理实际清理后才确认释放，未获许可绝不请求目标。拒绝不是重新准备或自动重跑的许可。结果默认保留30天、管理审计90天，控制服务按部署清理周期及`cleanupBatchSize`（默认100，范围1–1000）有界回收已归档且无活动引用的payload。过期报告显示不可下载；提交去重、许可、ACK摘要及hash/长度仍保留，重复上传不会复活已到期BLOB。旧未知归档时间保守从新锚点计保留期，不清公共快照；代理未确认结果不因该期限丢弃。

升级与回滚前停止接收新任务，等执行释放和结果归档，确认进程停止后备份控制数据、独立代理账本和单独密钥。F7c 控制端、客户端和代理须配套升级；旧代理因构建/能力不匹配不可选，不承诺新旧热混用。保留旧报告和账本，记录源 SHA/未提交差异摘要、Core/scriptApi/Node/V8 身份与镜像摘要；回滚恢复匹配的程序、数据备份和密钥，禁止两个代理共用账本目录。不要将取消通知或开始上传当作排空完成。

验证入口为 `scripts/test-all.ps1`（固定 Node/pnpm/JDK 的生产者拓扑、schema 漂移、src+tests 类型、包串行最多 2 worker、Java 测试）和 `node scripts/smoke-runner-agent.mjs`（实际新镜像部署冒烟）。定向真实联验为 `pnpm -C apps/runner-agent exec vitest run tests/e2e-server.test.ts --maxWorkers=1`，使用独占私有 Java 目录和合成材料。实际桌面/浏览器中英文布局仍需集中视觉验收，DOM 或构建成功不替代页面验收。
