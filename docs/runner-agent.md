# 自托管在线执行代理

桌面客户端负责项目接口、环境、数据、认证和测试定义。管理台负责代理基础设施、工作区授权、项目分配、项目关联和执行策略。执行位置与环境分别选择；指定代理不可用时不会自动改到本机或其他代理。

首版独立代理为 Linux 容器，使用 Node 22.19.0 / V8 12.4.254.21-node.29；Windows 桌面使用 Electron 44.1.0 内嵌 Node 24.19.0 / V8 15.2.124.18-electron.0。运行准入同时校验精确 Node/V8、脚本 API 身份、Core 构建身份和能力。未知组合先拒绝；更换镜像大版本、Electron 或依赖后必须重新取得同 Core 语义证据。当前候选的最终产物摘要与验收状态见阶段交付报告，不能拿历史包代替。

支持单接口调试、测试套件和 v2 工作流；只有真正无脚本的单请求调试复用常驻 worker，带脚本调试、套件和工作流各占完整独立任务进程。两条路径共用总任务槽，默认并发 1，可配置并发 2 或其他部署许可值；降低额度等待已有任务排空，不终止旧任务。显式 Cookie 会话绑定服务、项目、提交者和代理，普通取消只影响本次调用。worker 整代退出会如实标记受影响调用中断。

受信同步脚本沿用现有 Core 的 `pm.variables`、`pm.environment`、`pm.request`、`pm.response` 和 `pm.assert`。脚本按实际版本批准或显式信任整个项目；版本变更使单版本批准失效。脚本可能接触本次获授权的认证材料，因此批准应由项目管理员完成。这里使用现有 `node:vm` 语义，不承诺隔离恶意代码；DEF-001 未恢复，不包含 WASM/QuickJS、任意宿主 API、自动 npm/插件加载、代理压测、定时执行或 Windows 代理安装器。

项目凭据在后端使用独立 32 字节原始主密钥加密；主密钥不在数据库或镜像里。个人临时凭据可仅保存在本机，不自动上传；含仅本机材料时指定代理先拒绝。任务固定快照、凭据版本、附件版本和脚本依赖，准备声明由代理调用同 Core 重算，后端许可后才执行。Java 控制服务不复制 Core 执行算法，也不启动 Node 准备服务。

配置时长单位为毫秒、存储预算为字节、子进程堆上限为 MiB。配置保存版本与已应用版本分开；影响旧 worker 的项等待排空或重启，页面显示原因和待应用字段。部署默认经真实 Properties/环境绑定后记录持久检查点，重启改变继承值时推进版本并重新下发；显式代理覆盖仍优先。仅收到配置不等于已经应用。

控制链仅接受规范 HTTPS `/api/v1` 地址；`apicc.execution.control-base-url` 是部署身份，不从 Host/Forwarded 头推断。私有 CA 文件局部挂载给代理并保留证书与 SAN 校验。参见 [Compose 示例](../deploy/runner-agent/README.md)，其中主密钥、服务证书、代理 CA、身份 token、控制数据卷和代理账本卷分别管理。

代理使用 Node 内置 SQLite 持久账本和 owner/child lease。控制断线后已开始任务继续至本地期限；代理重启不会自动续跑或重跑业务，结果按原字节重传并等待归档确认。逻辑结论、真实请求事实、执行资源释放和结果归档分别显示。SQLite 的实验性告警如实保留；首次部署应配置足够磁盘与结果预留，本文不宣称已做 OOM/磁盘填满或全天运行专项。

开始前批准、权限或额度发生变化时，控制服务可持久返回明确的启动拒绝及安全原因；代理实际清理后才确认释放，未获许可绝不请求目标。拒绝不是重新准备或自动重跑的许可。结果默认保留30天、管理审计90天，控制服务按部署清理周期及`cleanupBatchSize`（默认100，范围1–1000）有界回收已归档且无活动引用的payload。过期报告显示不可下载；提交去重、许可、ACK摘要及hash/长度仍保留，重复上传不会复活已到期BLOB。旧未知归档时间保守从新锚点计保留期，不清公共快照；代理未确认结果不因该期限丢弃。

升级与回滚前停止接收新任务，等执行释放和结果归档，确认进程停止后备份控制数据、独立代理账本和单独密钥。记录源 SHA/未提交差异摘要、Core 身份与镜像摘要；回滚恢复匹配版本，禁止两个代理共用账本目录。桌面关闭不停止独立代理，重新打开后可查询后端任务。

验证入口为 `scripts/test-all.ps1`（固定 Node/pnpm/JDK 的生产者拓扑、schema 漂移、src+tests 类型、包串行最多 2 worker、Java 测试）和 `node scripts/smoke-runner-agent.mjs`（实际新镜像部署冒烟）。定向真实联验为 `pnpm -C apps/runner-agent exec vitest run tests/e2e-server.test.ts --maxWorkers=1`，使用独占私有 Java 目录和合成材料。实际桌面/浏览器中英文布局仍需集中视觉验收，DOM 或构建成功不替代页面验收。
