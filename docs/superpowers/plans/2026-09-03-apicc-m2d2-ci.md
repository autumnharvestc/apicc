- [ ] **步骤 2：实现**

- `scripts/check-brand-neutral.mjs`：
  - 词表：竞品工具名的分段字符串二维数组（每词拆两段，运行时 join），拼好后构造 `new RegExp("\\b(" + words.join("|") + ")\\b", "i")`；**脚本注释说明拆段原因（品牌中立约束对代码成立：入库文件不出现字面竞品名）与 swagger/openapi/collection 属开放标准命名不在词表**。
  - 输入：`git ls-files -z`（子进程 `git`，cwd=仓库根）；跳过 `pnpm-lock.yaml` 与二进制扩展（.png/.ico/.icns/.exe/.node）；逐文件逐行匹配，命中收集 `{file,line,text}`；有命中 → 全部打印后 `process.exit(1)`。
  - `--self-check`：运行时构造的正负样本断言（正样本必须命中、负样本必须不命中），任一失败 exit 1。
- `.github/workflows/ci.yml`：
  - `name: CI`；`on: push`（分支 main + `feature/**`）+ `pull_request`；`permissions: contents: read`；`concurrency: group ci-${{ github.ref }} cancel-in-progress: true`。
  - job `test`（ubuntu-latest）：checkout@v5；pnpm/action-setup@v4 `version: 11.21.0`（与本地一致，注释注明与 lockfile v9 兼容）；setup-node@v4 `node-version: 22` + `cache: pnpm`；env `ELECTRON_SKIP_BINARY_DOWNLOAD: "1"`（unit/typecheck 不需要 Electron 二进制，省 ~100MB 下载）+ `electron_mirror` 不设（跳过下载后无谓）；`pnpm install --frozen-lockfile`；`pnpm -r build`；`pnpm -r test`。
  - job `brand-gate`（ubuntu-latest）：checkout@v5（`fetch-depth: 1` 够用，git ls-files 基于索引）；setup-node@v4 node 22（跑 mjs 无需装依赖）；`node scripts/check-brand-neutral.mjs --self-check`；`node scripts/check-brand-neutral.mjs`。
  - job `package-smoke`（windows-latest，`if: github.ref == 'refs/heads/main' && github.event_name == 'push'`）：checkout；pnpm setup；setup-node + cache pnpm（**不设** ELECTRON_SKIP_BINARY_DOWNLOAD——builder 需要 Electron dist）；`pnpm install --frozen-lockfile`；actions/cache@v4 缓存 `~\AppData\Local\electron\Cache` 与 `~\AppData\Local\electron-builder\Cache`（key 含 runner.os + 固定前缀）；`pnpm -C apps/desktop gen:icon`；`pnpm -C apps/desktop dist:dir`；`pnpm -C apps/desktop smoke:dir`。注释注明 `.npmrc` 的 npmmirror 镜像对 GitHub runner 可达，若未来不可达改设 `ELECTRON_MIRROR=https://github.com/electron/electron/releases/` 官方源。
  - action 版本注释：每个 uses 行尾注释锁定的 major（如 `# v5`）。
