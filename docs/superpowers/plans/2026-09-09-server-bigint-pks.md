# 服务端 BIGINT 主键化（批 3）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 8 表中实体身份 id 全部从 UUID 字符串切 64 位整数（BIGINT IDENTITY），id 生成策略可插拔（默认数据库自增），对外 JSON/URL 仍为字符串化数字，语义字段零改动（规格：docs/superpowers/specs/2026-09-09-server-bigint-pks-and-member-ux-design.md 缺陷一）。

**架构：** DDL 一处（schema.sql）；Java 全链 Record/Repo/Service `String→Long`，View/DTO 组装处 `String.valueOf` 保持对外字符串；4 个实体 insert 改「identity 模式 = 不带 id 插入 + KeyHolder 取回并回填记录」；新增 `IdGeneration` 策略接口（identity 默认，appAssigned 预留外部策略如雪花）；路径 id 解析经 `EntityIds.parse`（非数字 → 400 validation_failed）；`ContentPaths`/桌面 `session.ts` 两处 PROJECT_ID_PATTERN 改 `^\d+$`。无迁移——删库重开口径（schema.sql 头注已有）。

**技术栈：** Spring Boot 3 + JdbcTemplate（GeneratedKeyHolder）、H2（IDENTITY 与 PG 同语法）、vitest（desktop）。

**环境约束（务必遵守）：**
- 服务端：`JAVA_HOME="C:\Program Files\Java\jdk-21.0.12" mvn -s server/.mvn/settings.xml -f server/pom.xml test`。
- desktop：worktree 根先 `pnpm install`；跑测试 `pnpm --filter @apicc/desktop test`（fresh worktree 若 e2e 冒烟因缺 dist 文件级失败，先 `pnpm --filter @apicc/admin-web build`）。
- 写代码禁用 heredoc；块注释内禁出现「星号斜杠」序列；中文注释、块注释注明规格来源。

**全局不变量（每个任务审查的注意力透镜）：**
1. **对外 JSON 的 id 一律字符串化数字**（View/DTO 字段类型保持 `String`，赋值处 `String.valueOf(...)`）。桌面契约 `z.string()` 与夹具零改动为验收标准。
2. **语义字段零改动**：`token_hash`（SHA-256 自然主键）、`file_versions.path/content_hash/version`、`users.username/password_hash/display_name/role/disabled`、时间戳列、`groups.is_default` 一律不动；`file_versions` 的 (workspace_id, path) 复合主键结构不动。
3. **删除全部 `UUID.randomUUID()` 生成点**（server/src/main 下 10 处，清单见任务 2/3）；本地工作区（desktop `main/session.ts` 轨一/轨二目录 id）的 randomUUID **不在范围**，禁碰。
4. **`IdGeneration` 可插拔**：接口 `boolean appAssigned(); long nextId();`；默认实现 identity（`appAssigned()=false`，插入走 KeyHolder）；配置 `apicc.id-generation`（默认 identity；未知值启动即 fail-fast；snowflake 本体本轮不实现）。repo 插入按 `appAssigned()` 分支：true = `nextId()` 显式带 id 插入。
5. **URL/请求体中的 id 解析**：统一经 `core/EntityIds.parse(String): long`——`Long.parseLong` 失败抛 `ApiException(BAD_REQUEST, "validation_failed", "id 必须是数字")`。受影响测试里「随机 UUID 探 404」改「不存在的大数字（如 999999）探 404」，另补「非数字 → 400」断言。
6. **Record 的 id 组件**：类型 `Long`（构造时 null = 待生成）；repo insert 返回**补全 id 的新 Record**（KeyHolder/appAssigned 分支后 copy）。
7. **测试夹具新口径**：直构实体用 `null` id 或小整数（1L/2L）；插入后从返回值/JsonPath 取真实 id；不再手写 UUID 常量。

`IdGeneration.java`：

```java
package com.autumnharvestc.server.store;

/**
 * 实体 id 生成策略（规格 2026-09-09 BIGINT 化口径 2）：可插拔——默认 identity=数据库自增
 * （插入不带 id、KeyHolder 取回）；外部策略（如雪花）实现 appAssigned()=true，仓储插入前
 * 经 nextId() 预生成显式插入（DDL 用 GENERATED BY DEFAULT AS IDENTITY，两种形态共存）。
 * 本轮只交付 identity；snowflake 等按需另配实现类。
 */
public interface IdGeneration {

    /** true = 应用侧预生成（insert 前 nextId()）；false = 数据库 IDENTITY 自增。 */
    boolean appAssigned();

    /** 应用侧生成下一个 id（仅 appAssigned()=true 时被仓储调用）。 */
    long nextId();
}
```

`DatabaseIdGeneration.java`：

```java
package com.autumnharvestc.server.store;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

/**
 * 默认策略：数据库 IDENTITY 自增（规格 2026-09-09）。配置 apicc.id-generation 仅接受
 * identity（默认）；显式配置其他值即启动失败——外部策略应提供自定义 IdGeneration Bean，
 * 而非在此硬编码开关。
 */
@Component
public class DatabaseIdGeneration implements IdGeneration {

    public DatabaseIdGeneration(@Value("${apicc.id-generation:identity}") String strategy) {
        if (!"identity".equals(strategy)) {
            throw new IllegalStateException("不支持的 apicc.id-generation: " + strategy + "（当前仅 identity；外部策略请提供自定义 IdGeneration Bean）");
        }
    }

    @Override
    public boolean appAssigned() {
        return false;
    }

    @Override
    public long nextId() {
        throw new UnsupportedOperationException("identity 策略由数据库自增，不走应用侧生成");
    }
}
```

`EntityIds.java`：

```java
package com.autumnharvestc.server.core;

import org.springframework.http.HttpStatus;

/**
 * URL/请求体中实体 id 的解析守卫（规格 2026-09-09 BIGINT 化口径 5）：对外是字符串化数字，
 * 进服务层前统一 parse；非数字/空白一律 400 validation_failed——不放进各控制器散写。
 */
public final class EntityIds {

    private EntityIds() {
    }

    public static long parse(String raw) {
        if (raw == null) {
            throw new ApiException(HttpStatus.BAD_REQUEST, "validation_failed", "id 必须是数字");
        }
        String trimmed = raw.trim();
        try {
            return Long.parseLong(trimmed);
        } catch (NumberFormatException ex) {
            throw new ApiException(HttpStatus.BAD_REQUEST, "validation_failed", "id 必须是数字: " + trimmed);
        }
    }
}
```

（`ApiException` 构造器形态/code 取法按 `core/ApiException.java` 实际调整；`GlobalExceptionHandler` 已有 400 映射则零改动。）
