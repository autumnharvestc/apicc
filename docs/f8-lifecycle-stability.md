## 用户已确认的生命周期方案

用户已明确答复“采用该方案，继续实施”。下列默认值、范围和清理副作用均按该确认落地。

### 客户端缓存

原 `onlineExecution` 为执行位置/环境、调试会话引用、最近运行分别维护 Map，跨项目切换保存但没有统一边界；本批增加共同的上下文生命周期管理。

以服务器、用户、工作区、分组、项目的稳定身份元组为上下文归属，不依赖对象属性顺序。当前上下文、仍有本机请求在途、代理任务未实际释放或报告待归档、结果不确定的上下文均受保护；不能按“页不可见”即删除。只有明确安全的非活动缓存可清理，清理不发送取消、重跑、撤销或删除服务器历史。

| 配置 | 默认 | 范围 | 生效方式 |
| --- | --- | --- | --- |
| 非活动上下文缓存上限 | 20 个 | 0–200 个；0 为不保留可清理的非活动缓存 | 本机应用设置，保存后对安全缓存生效；不强制驱逐受保护记录 |
| 非活动空闲保留期 | 30 分钟 | 1–1440 分钟 | 非活动空闲期使用单调时钟；在上下文切换、运行结算、状态确认及配置保存时清理，无需独立常驻计时服务 |
| 非活动结果载荷预算 | 64 MiB | 1–512 MiB | 按缓存序列化载荷的字节估计，先释放最久未用的安全缓存；不是进程堆或 RSS 硬限制 |

缓存上限是可清理非活动上下文的数量边界，不是 Electron 进程 RSS 的硬保证。活动/不确定记录单独计数，不能用驱逐换取指标达标。释放缓存会丢弃本机执行位置/环境选择、旧调试会话引用及已完成结果的内存副本；再次进入默认使用本机位置，可明确读取服务端历史。下一次显式调试可能建立新调试会话，不能把旧 cookie/变量续用当成保证。配置入口需同时说明这些行为，参数仅保存在本机，不进入项目资产或服务端执行策略。

`run` 的 Promise 结束不等于执行已释放：RPC 后没有明确结果/任务的失败按不确定保护。保护引用必须覆盖该上下文所有已知未释放/未归档任务的最小身份，不能只看最新运行，也不能因列表仅返回最近 20 条就判旧任务已结束。保护记录不参加安全缓存驱逐；旧状态只凭明确的终态/释放/归档事实解除，不能靠空列表或网络失败推断。

实现中所有已知任务只保存必要身份引用；原有可见页面状态查询按最多 20 项轮转，某项读取失败保留其保护、显示首个错误并继续后续项。列表缺项不移除引用，隐藏上下文不增加后台轮询。不确定 RPC 没有自动重跑或猜测解除路径。最近运行只保留 target 的 kind 元数据，完整调试请求仍按原契约传给 RPC，不额外长期复制在缓存内。

顶栏原有“设置”抽屉增加“在线执行缓存”，主页及未登录时也可配置。三个参数仅存本机，保存持久化成功后才应用；写失败保留旧策略与草稿。页面以中英文表单、单位、当前/受保护/安全非活动计数和载荷估算直接展示，没有 JSON 主视图。

### 代理账本

账本仍是 SQLite 中的一个原子 JSON 状态，包含 intents、未 ACK 消息与 commands。原有确认归档会移除报告正文，但还保留进程明细/启动意图。仅按时间或 LRU 删除 executionId / commandId 会损坏跨重启、离线及重复投递保护，不能实施。

只压缩已结束、报告归档回执匹配、相关消息均已 ACK、所有已记录进程均明确退出且不存在不确定进程状态的记录。保留 executionId、jobId、deliveryId、执行事实、settled/archived 标记及必要进程总体；只删除 processes/processIntents 逐项明细。不删除 commands 身份，不压缩活动任务、未 ACK 项、未上传报告或未知进程。

压缩复用现有账本原子提交边界，不引入额外后台服务、第二份恢复状态机或新的控制协议。新归档/ACK 时在同一次原子写中收敛符合条件的记录；旧记录在进程恢复、seen/messages 恢复完成后按有限批量处理，保留渐进游标。两个 ACK/归档顺序都支持；写入失败保留原内存和 SQLite 状态，并沿用 unhealthy/抛错策略，不吞错。

部署文件增加 `ledgerCompaction.enabled`（默认 true）及 `ledgerCompaction.batchSize`（默认 50，范围 1–1000），重启生效；不扩共享 AgentConfig、控制 wire 或 Core 执行身份。每次资格检查/压缩条数有界，但 pending 索引、现有账本 clone/stringify/原子重写整份 JSON 仍随体积增长，不因此承诺 CPU、I/O 或数据库总量有界。每个 spawn intent 必须匹配同 id/role/scope/epoch 且明确退出的进程；空进程列表、未知/冲突 legacy 结构、不确定进程状态均不压缩。

轻量永久防重身份仍随历史任务增长；本批不能宣称其总量有限。未来若需要删除身份，必须先设计服务端确认水位、旧命令不可重放证明及版本化恢复协议，再单独批准实施。
