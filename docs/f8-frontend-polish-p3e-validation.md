## 过程发现与修正

1. 导航焦点及双语空态5个实例均在实现前观察失败；历史首轮测试误把标题写为 History，随后先改为准确的段落断言，保留02原记录，03才作为该文案的有效失败证据。其他原测试并未宣称新增先红。
2. 浏览器发现原隐藏辅助标签的绝对定位跨出滚动容器，根可滚高度4913，点击控件会带动顶部。已给标签的字段容器定位，并将隐藏标签锚在字段左上；修正后根高900、可滚高900、scrollTop 0。该样式修复以实际浏览器几何及图验收，不用镜像CSS测试。
3. 短高下说明区单独局部滚动，搜索、导航和关闭在其外；480宽统计卡为两列。所有样式限定 `.sync-panel`，移除旧全局 `[role=alert]` 选择器。
4. 独审发现浏览器合成 detail DTO 缺身份字段，且最初contentType不合法；在执行原文成功验收之前改用完整 `SyncFixedDetailSchema.parse`，再经过真实store加载成功。未将早期夹具当作成功证据。合成原文使用合法YAML的JSON子集，业务原文允许直接展示。
5. 部分自动化定位初次名称未匹配，依据实际DOM纠正后复核；回滚禁用证据同时确认真实按钮存在1个，未把不存在元素等同禁用。
