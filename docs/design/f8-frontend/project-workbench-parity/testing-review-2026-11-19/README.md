## 施工与验收

- 两端使用相同窗口尺寸、项目样本和选择状态，比对页头、列边界、列表高亮、按钮与底栏。按模式接回已有功能和权限，包括本地场景用例、在线压测计划。
- 数据集和套件分别检验选中、未选中、切换时保留草稿。核对列表选中项、编辑器绑定及保存或删除的目标身份。同名对象也逐项核对。
- 压测页按图 06 验收。待确认时由按钮表达下一步。显式确认且其余条件满足后才可启动；授权目标或执行位置改变后须重新确认。失败原因贴近相应字段或操作。
