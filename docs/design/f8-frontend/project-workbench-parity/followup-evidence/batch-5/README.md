### 操作回读

- 在线历史工作流由计划 2 实际触发，任务 9、执行 10，代理 1。计划执行后改存为每日规则；截图中的未来预览对应现行配置，历史发生时的规则版本仍为 1。「运行记录」打开原触发记录，其「查看原任务报告」准确选中 `1/9/10`；「返回原计划」恢复计划 2。打开两端报告后，均见成功的健康检查、故意失败的断言及实际 1 次 HTTP 交换。上述打开与返回前后，接收端业务 HTTP 33→33、代理任务 4→4。
- workspace 1 的事件 2 关联计划 2、任务 9、执行 10。实际 Webhook 接收器在独占合成网络收到该事件，返回 200；服务端投递行 `acknowledged / 1 / 200`。任务最终归档，通知保留生成时的 `failed / pending`；该快照没有采集实际开始时间。「查看本次运行」选中 `1/9/10`，「查看计划」选中「订单夜间回归」，每次「返回原通知」均恢复事件 2。跳转后服务端仍为未读。
- 显式将事件 1 标为已读，经服务端回读只有事件 1 由未读变为已读，事件 2、3 仍未读，业务请求和任务保持 33 / 4。780 × 370 窗口的记录列表裁切下沿为 y331，事件 1 所关联的任务行顶缘为 y356。从通知定位后仍选中该行的原始 `1/1/2`，返回恢复同一已读事件。此处验证了列表可视区外定位；真实任务页只有 4 条。
- 合成暂停事件 3 无 jobId / executionId，显示「此通知没有关联运行」，运行按钮禁用。使用其版本号删除本次创建、已暂停且没有执行的原计划 3，再点「查看计划」保留事件 3，提示关联记录不可用或无权查看；未打开其他计划，业务请求和任务数保持 33 / 4。
- 在线项目使用「本机」运行慢请求 `02449bb0-6e2d-4f31-8f58-2555f9858848`。接收端先看到了同一 GET /slow 的连接，停止后连接被取消。任务视图自行回读为「已结束／已接收／已取消」，请求执行事实显示「是否执行尚不确定」。原主进程只读回查得到 `cancelled / uncertain / local-run-cancelled`。第三批旧记录 `687aeed2-4598-4c59-a9e0-9233860e4bc7` 在原主进程也回读到同样三项。查看或切换同名压测计划没有再次执行或停止其他计划。
