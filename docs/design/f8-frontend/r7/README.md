- [真实 200 的响应首屏](batch-3/preview-initial-200.jpg)

## 最终 Windows 候选包

- [默认分隔下的两行查询参数和真实 200](final/final-200.jpg)
- [拖动分隔后的响应正文](final/final-split-drag.jpg)
- [真实 503 与失败摘要](final/final-503.jpg)
- [同位取消和可读结果](final/final-cancelled.jpg)

最终包用与 P5 对照相同的订单、两个项目签、开发环境和回环服务。两轮采用相同的默认启动窗口和应用缩放。实际捕获范围 P5 为 1087×633，r7 为 1097×638。P5 要滚过响应外层才能看到查询参数与正文，r7 默认首屏同时露出两行查询参数、响应摘要、搜索框及七行正文。r7 顶部只用一行容纳主页、项目签、全局工具和窗控。响应分隔抓手从截图 y=373 拖到 y=331，Enter 恢复默认。切回订单签保留查询页、开发环境和 200 结果。回环日志记录 GET `/echo?orderId=ord_001&includeItems=true`、`/fail` 及 `/slow`，慢请求在约 3.5 秒取消并于响应完成前关闭。截图、可访问树、客户端日志和 HTTP 日志见 `local/f8-frontend-r7/isolated-j5G3Ly/`，隔离客户端正常退出。

交付为免安装目录 ZIP `local/f8-frontend-r7/apicc-f8-workbench-r7-win-x64-final.zip`，180980396 字节，292 条目。ZIP SHA-256 为 `45d1c2176c96af1485a821c682dfd6260a312967ce689a3de08d98ce76d3b24c`，其中 `resources/app.asar` 的 SHA-256 为 `2976dfa1459858433eaaaad61b0616a3ac009bedd1c66a553c33948e2aacb773`，与已冒烟且原生实跑的目录包一致。打包日志、冒烟、源文件与压缩包哈希清单在 `local/f8-frontend-r7/candidate-final/`。基准提交 `1baa951c`，包中还包含本工作树未提交的 r7 源码。
