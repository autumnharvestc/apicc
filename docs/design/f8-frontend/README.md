# F8 可交互视觉样板（P0）

打开 `index.html` 查看工作台、运行报告和管理配置三页。若浏览器限制本地脚本，使用 Node 22 运行 `node docs/design/f8-frontend/serve.mjs`，再打开终端输出的 `http://127.0.0.1:<端口>/`。该服务器只提供三个指定样板文件，不暴露仓库或业务接口；结束进程即停止。

所有值均为合成数据，编辑/保存/发送/删除仅改变样板内存；刷新恢复。无认证、网络请求、真实项目读写或持久化。禁用按钮为尚未演示的产品入口，不表示实际产品功能缺失。

可验证：

- 顶部三页切换、中英文与深浅色切换。
- 工作台目录搜索、悬停/键盘聚焦图标、合成重命名/删除、参数编辑及保存、模拟响应失败/恢复。
- 报告常驻搜索、失败筛选、清除搜索保留勾选、空状态恢复、展开详情/完整指纹/原始数据。
- 管理页覆盖值验证、本地模拟保存后版本 8 待应用而实际仍为 7；批准区域只读。

产品风险与逐点验收在上级 `f8-frontend-polish-design.md`、`f8-frontend-polish-acceptance.md`。本样板是视觉方向评审材料，不是生产功能实现，也不代替产品或原生窗口验收。
