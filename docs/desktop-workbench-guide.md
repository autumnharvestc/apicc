# 桌面工作台使用指南

## 打开项目与选择环境

从主页打开本地目录中的项目，或通过「管理连接」登录并打开在线项目。顶栏的每个项目签有各自的工作位置。切回已打开的项目签可继续浏览原先的接口、用例、环境或任务记录。对象已删除或访问权限已收回时，从仍可访问的列表重新选择。

在窗口底栏选择本项目执行时使用的环境。进入侧栏「环境」可以编辑变量、参数和环境定义。要在某个环境运行，直接在底栏选择即可。在线项目还可以选择执行位置。地址中的 `localhost` 和 `127.0.0.1` 都指向实际发出请求的机器。若服务只有集成环境的网络能访问，应选能连接该服务的代理。

## 从调试请求建立用例

1. 进入「接口」，选择接口并填写请求参数，点击「发送」。查看响应头、响应体或断言。选择「收起」可以把空间留给请求编辑器。
2. 进入「测试 → 单接口用例」，选择该接口，在用例列表新建或打开用例。用例可以继承接口默认请求，也可以保存其独立请求。本地项目可用「应用当前调试草稿」将调试中的修改带进用例。Cookie Jar 归属当前桌面进程的会话；保存用例不会打包当前会话的 Cookie。
3. 添加断言或响应提取。响应提取将结果写入本次运行的变量；可选提取缺失且没有默认值时，清除这一层的旧值。其他作用域的同名变量仍可能生效。保存后使用「运行」验证该用例。

用例的前置、后置操作按执行路径运行。调试历史保留当时已采集的证据。查看记录不会重发请求；从报告定位回编辑区时看到的是当前资源。

## 数据集、测试套件与工作流

在「测试 → 数据集」维护行和列。字符串 `"1"`、数字 `1`、空字符串、没有这个字段和 `null` 在测试中可以产生不同结果。需要保留类型时用 JSON 导入导出；CSV 用于文本交换。旧版的本地文件引用从工作区根目录解析。

在「测试套件」选择用例、设置顺序，展开预览核对运行范围。选择由套件按数据行驱动或由子用例驱动，避免在同一执行路径同时绑定两层数据。套件中各条目及外层数据轮次隔离变量和 Cookie。要把创建订单返回的编号传给查询订单节点，应在工作流中编排这两个步骤，并使用响应提取。

子流程仅发布显式配置的成功输出。并行 OR 分支仅发布实际胜出者的输出，其他分支取消并收尾。循环轮次与数据行分别计数。循环零次时没有输出，while 循环用尽预算时条件仍成立则判失败。

重试请求节点可能再次发出已经到达远端的请求，此前发生的远端写入和会话 Cookie 不会回滚。取消或达到总期限时，运行等待在途调用收尾，并停止发起新的网络补偿或 finally 请求。处理局部超时仍受整次运行总期限约束。

## 发起、确认与查看任务

在「运行 → 发起任务」选择目标，核对右侧预览、环境和执行位置，再点击对应运行按钮。本地「模块用例」按当前模块及下级文件夹列出适用用例。在线任务使用项目获准的执行位置；本机任务依赖桌面进程，关闭客户端后不会由代理自动接手。

代理已接收的任务独立于桌面窗口运行。控制连接中断后，重新打开项目，在「任务记录」查原任务。断连本身无法说明执行结论，重新连接也不会重新发起该任务。

在线压测计划保存目标、负载和环境等配置。启动前核对本次执行的进程数、实际位置及授权目标。先点击「确认目标与执行位置」，再点「开始压测」。改变授权所指的对象或执行位置后需要重新确认，在本机回环地址上压测也一样。本地项目首次发起压测时，在目标授权框选择仅允许本次，或在信任该项目时选择项目授权。

任务记录中的「已结束」描述任务生命周期；通过、失败或取消描述执行结论。停止后的记录可能只能证实任务已取消，无法证实已经发出的单个请求有没有到达服务端。历史环境与执行位置取自那次运行；标有「当前名称」时，页面用记录里的原始 ID 查找今天的显示名称。

## 在线计划与通知

定时任务按保存的计划快照使用指定目标、环境、代理和材料。修改项目底栏只改变当前项目交互时的执行选择。需要让计划使用新的配置时，在计划中刷新快照并确认；已形成的任务按各自当时的配置运行。

通知可分别进入「查看计划」及「查看本次运行」。一次触发若尚未形成执行事件，页面会给出对应原因。执行结果、报告归档和通知投递可以处在不同状态。例如断言失败后，Webhook 仍可能成功收到这条失败通知。打开详情、返回通知或标为已读均不会重跑任务。

## 代理脚本、项目工具与个人设置

代理可运行获准的受信项目脚本。Core 的同步 pm 接口支持变量、环境读取、请求与响应和断言。脚本依赖需符合该执行位置的运行能力。本机可以使用用户登记的受信插件，代理使用内置能力。脚本可能接触请求中的认证材料。授予整个项目脚本信任时，批准范围也覆盖以后修改的脚本。遇到授权阻断时，按页面列出的代理、项目及脚本版本核对批准记录。

项目工具中的 Mock 启动和重载使用最近保存的项目快照。外部规范同步先生成候选变更，核对后再应用。通过 AI 辅助生成用例、断言或分析报告时，核对实际选择的材料和本次外发预览，修改选择后重新预览。个人模型连接在设置中维护，连接测试和模型发现需要显式发起。

外部规范同步的获取配置从下一次检查生效。Git 工作目录的磁盘阈值按采样监测，内容字节预算按项目和宿主计算。分享项目材料时先核对预览中的内容。已发布的固定副本、成员上传的历史和访问授权各自有保留或到期条件；需要停止分享时，到对应的授权或发布记录操作。

在「设置 → 在线执行缓存」可调整非活动上下文的容量、空闲时间与数量。在途、仍须释放或归档、运行状态未确定等记录受到保护。可安全释放的执行上下文被清理后，该项目下次的执行位置恢复为本机，环境恢复默认，调试也可能建立新会话。服务端已保存的历史仍可从对应项目查看。

「清理的影响」列出估算口径和触发时机。容量按序列化载荷估算；切换上下文、运行结算或保存设置时会检查空闲期限。清理可能释放已完成本机结果的内存副本，不会取消或重跑请求。

插件在桌面启动时从用户清单加载。在设置中刷新可检查当前进程的加载结果；修改清单后重启桌面端。安装方法见[插件开发与使用指南](plugins.md)。
