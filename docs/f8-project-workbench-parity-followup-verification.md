# 工作台六批施工验收

本记录随[实施计划](f8-project-workbench-parity-followup-plan.md)逐批更新。定稿、行为证据和实机图分别核对，验收使用独立的合成工作区。

## 第一批 · 目录与工作位置

| 计划项 | 验收结果与证据 |
| --- | --- |
| 1.1 | 两端搜索内部配置均无配置文件入口。名为 `project.yaml` 的真实 GET 接口仍可选中并编辑。空模块及空目录可见。[两端目录实拍](design/f8-frontend/project-workbench-parity/followup-evidence/batch-1/README.md#目录草稿与失效回退) |
| 1.2 | 两个本地项目和一个在线项目依次切签，再按原路返回，分别恢复「环境 → 本地 1」「测试 → 订单样本」「运行 → 原任务」。实机首次发现侧栏与正文分离，补入两个 App 组合回归，修订后逐步截图。业务 HTTP 5→5，代理任务 1→1。[六步往返](design/f8-frontend/project-workbench-parity/followup-evidence/batch-1/README.md#三个项目往返) |
| 1.3 | 双端复核工作流节点、画布、草稿、已有 503 响应及环境编辑位置。本地另核请求签与调试／设计子页；在线核已有的请求编辑子页。在线接口编辑器现有功能不含独立设计器。工作流与 503 项的实机记录来自初版，修订版复查了数据集与记录恢复。 |
| 1.4 | 删除数据集后移除旧选择并保留同名可用对象。Viewer 整项目失权可返回所属在线工作区、打开仍有权访问的同级项目。实服允许列出项目名称，对已失权项目资产返回 403。迟到读取与主动定位另有定向行为测试。[各场景记录](design/f8-frontend/project-workbench-parity/followup-evidence/batch-1/README.md) |

开发回归包括真实挂载 App 的双项目切签、旧档案身份不足回列表和返回操作的选中状态。独审另外运行了原入口 10 项、边界探针 4 项，并单独复验撤权返回。桌面 Vue 类型检查通过。
