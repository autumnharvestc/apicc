# 工作台六批施工验收

本记录随[实施计划](f8-project-workbench-parity-followup-plan.md)逐批更新。定稿、行为证据和实机图分别核对，验收使用独立的合成工作区。

## 第一批 · 目录与工作位置

| 计划项 | 验收结果与证据 |
| --- | --- |
| 1.1 | 两端搜索内部配置均无配置文件入口。名为 `project.yaml` 的真实 GET 接口仍可选中并编辑。空模块及空目录可见。[两端目录实拍](design/f8-frontend/project-workbench-parity/followup-evidence/batch-1/README.md#目录草稿与失效回退) |
| 1.2 | 两个本地项目和一个在线项目依次切签，再按原路返回，分别恢复「环境 → 本地 1」「测试 → 订单样本」「运行 → 原任务」。实机首次发现侧栏与正文分离，补入两个 App 组合回归，修订后逐步截图。业务 HTTP 5→5，代理任务 1→1。[六步往返](design/f8-frontend/project-workbench-parity/followup-evidence/batch-1/README.md#三个项目往返) |
| 1.3 | 双端复核工作流节点、画布、草稿、已有 503 响应及环境编辑位置。本地另核请求签与调试／设计子页；在线核已有的请求编辑子页。在线接口编辑器现有功能不含独立设计器。工作流与 503 项的实机记录来自初版，修订版复查了数据集与记录恢复。 |
| 1.4 | 删除数据集后移除旧选择并保留同名可用对象。Viewer 整项目失权可返回所属在线工作区、打开仍有权访问的同级项目。实服允许列出项目名称，对已失权项目资产返回 403。迟到读取与主动定位另有定向行为测试。[各场景记录](design/f8-frontend/project-workbench-parity/followup-evidence/batch-1/README.md) |

开发回归包括真实挂载 App 的双项目切签、旧档案身份不足回列表和返回操作的选中状态。独审另外运行了原入口 10 项、边界探针 4 项，并单独复验撤权返回。桌面 Vue 类型检查通过。

## 第二批 · 选择安全与单接口用例

| 计划项 | 验收结果与证据 |
| --- | --- |
| 2.1 | 用两条同名数据集和两条同名套件验证清空与取消切换。拒绝丢弃草稿时，列表高亮、正文与原 ID 一致。独审额外验证取消进行中目标消失的情况。在线当前接口的一个已保存用例被删除时，保留可访问的用例列表，清空失效选择；同名幸存用例需显式选择。新建用例草稿在切页往返后仍可编辑。 |
| 2.2 | 双端「查询订单 → 已付款订单」实拍在同一尺寸下逐项对照 T01/T02。三栏左缘为 x=110、441、707，底栏上沿 y=896，四个主操作同位。单状态码样例的响应提取、前置、后置操作均在首屏；另一个包含两条断言的样例保留了路径编辑。780 × 720 窄窗下四个操作中心均可命中，详情区独立滚动。[在线](design/f8-frontend/project-workbench-parity/followup-evidence/batch-2/T01-online-case.png) · [本地](design/f8-frontend/project-workbench-parity/followup-evidence/batch-2/T02-local-case.png) · [单断言](design/f8-frontend/project-workbench-parity/followup-evidence/batch-2/T02-single-assertion.png) |
| 2.3 | 独审挂载实际在线工作台，验证默认首例、显式选中另一用例、请求覆写及恢复继承，回查发起的接口、用例、范围和版本。Viewer 无写入或执行权限，0 用例时保留授权成员的 AI 建议入口。 |

两端实机保存后独立读盘／读服，核对用例请求、数据、断言、提取、前后置操作。在线通过本机与 Linux 代理分别执行两次真实订单 GET，均返回 200。四组同名资产按 ID 回读，确认保存和删除只作用于所选的第二项。[第二批实机记录与截图](design/f8-frontend/project-workbench-parity/followup-evidence/batch-2/README.md)

## 第三批 · 数据集、测试套件与压测计划

| 定稿 | 行为与实机对照 |
| --- | --- |
| T03、T04 | 在两端选择及清空「订单样本」，高亮、表名、保存及删除入口随所选 ID 一同变化。101 行宽表实测局部横向滚动、翻页及 JSON 导入导出回读，区分文本、数字、空串、缺字段和 null。非法数字改为文本时保留刚输入的字符。CSV 按文本交换。 |
| T05 | 「订单回归」在两端预览 2 项 × 2 轮，业务端依次收到创建与查询订单，各重复一轮。套件和子用例同时绑定数据时在发送前拒绝，实际新增业务请求为零；取消其中一层绑定即可按预览顺序运行。相同接口／用例的多环境范围合为一个可选条目，不同接口仍按完整位置区分。 |
| T06 | 计划配置与本次执行在一个首屏内，三个数值字段与授权目标按列对齐，底栏切换位置。确认只登记授权；改变计划目标、环境、位置或授权地址后重新确认。显式启动本机压测收到两条 GET 并能从回执进入记录。同名计划按计划 ID、任务和执行回执判定可停止的对象，合成代理接受了原任务的停止请求。 |

在线代理实际收到取消请求；本机慢请求实测连接取消，桌面提交回执当时仍为「提交结果未确定」。保留这条记录，交第五批分别核对回执和报告能证明的事实。[第三批实拍、回读与业务日志摘要](design/f8-frontend/project-workbench-parity/followup-evidence/batch-3/README.md)
