# F8 P3c：数据集与测试套件

2026-11-08，基于 P3b 提交 `cd0fc256`。范围是本地 TestView 与在线 OnlineProjectAssets 共用的 DatasetPanel、SuitePanel；本组不修改执行器、store、在线适配器或侧栏导航。

## 展示与交互

- 数据集：固定保存栏，基本信息、数据表和导入/导出分区。保留 100 行分页、类型化 JSON 单元编辑、10 MiB 输入限制和导出格式捕获。导入预览改成前 100 行列对齐表，缺字段与 null、false、0、空字符串分别呈现；单元业务 JSON 原文允许保留。删除行、分页及单元输入提供明确名称。
- 套件：基本信息、选择条目、运行配置分区，既有执行工具栏常驻。选中条目的上移/下移有名称；预览按类型、预计执行次数、实际用例路径与 scope 展示，数据来源独立成表。结果保持逻辑报告单位与实际用例行的区别，条目状态、轮次及失败原因分列，证据/AI 绑定不变。
- 固定文案中英双语；仅映射明确的工作流状态 draft/published/enabled 和条目类型 case/workflow，未知码和业务名称/路径/scope 原样。长表局部滚动、表头不拆字，深浅主题复用已有变量。

## 验证

- 新增真实组件测试：导入预览的类型/缺值、第二页行删除与只读、套件预览/状态原文及条目移动、externalRun 的参数和原禁用条件。
- 复用 testingCenter 的保存/导出/查询/取消收束/迟到响应/分页回归及受影响 AI 接线测试；Vue 类型检查和 renderer 构建。全部是定向范围，不运行本地全量。
- 实际组件浏览器集中检查宽窄、中英、深浅与长内容；与原生/后端验收分开。冻结后复用既有独审者，归档证据并提交。
