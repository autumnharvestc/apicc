## 3. 视觉方向

采用现代、干净、紧凑的专业工作台。浅底工作区、白色面板、细分隔与低强度阴影区分层次；主操作采用克制的蓝色，状态另用绿/红/橙并附文字或图标。保留桌面现有浅色、深色和跟随系统能力。

- 正文 13–14 px，正文行高约 1.5；标题 18–24 px；代码/路径/数字使用等宽字体或等宽数字。主界面避免大面积营销式留白。
- 间距以 4 px 为基础，常用 8/12/16/24；常规控件高 32 px，紧凑行约 32–36 px。交互命中区不因图标缩小。
- 按钮、输入、选择、页签、徽标与弹窗形成一套层级；图标优先沿用已有图标库。示例的 SVG 仅是独立样板资产。
- 悬停只改变颜色/背景，不改变行高、宽度或使标题换行。次要动作预留固定区域，键盘聚焦时也可见；图标按钮有可访问名称和文字提示。
- 焦点始终可见；不单靠颜色表达状态；动画轻量并遵循减少动态偏好。可用、忙碌、只读、禁用、错误均明确可辨。
- 长表格保留正常表头与列宽，局部横向滚动；长标识可短显但完整值可查。不可用 `overflow:hidden` 遮住用户唯一可操作入口。

## 4. 三个样板

1. **桌面工作台**：工作区/项目顶栏，模块导航与树面板，接口页签，请求编辑器与响应。包含长名称、固定图标操作位、参数编辑、模拟执行失败/恢复、未保存状态。
2. **复杂报告**：逻辑迭代结果与原始请求失败分列，固定搜索/筛选，单时间桶趋势限制说明，节点、失败原因与证据详情。正文 JSON 允许作为请求/响应内容；报告元信息使用表格/摘要。
3. **管理配置**：项目代理设置、保存版与已应用版分开，继承值/覆盖值/单位可读，表单本地模拟保存反馈和错误提示；不创建、撤销或修改真实授权。

样板提供中文/English、浅色/深色切换，宽窗口/窄窗口/极短窗口布局可实看。该切换仅用于设计评审，不表示为管理台新增主题功能的产品决策。默认中文，合成业务名称不翻译。

## 5. 功能不变量

视觉改动不改变执行器选择、权限、任务取消、脚本批准、保存语义、脱敏、统计计算、网络授权或连接令牌绑定。若实际交互整改确需调整行为，先写出触发条件/预期状态/受影响调用方，纳入该批验收。

必须保护：

- 当前草稿、当前项目/连接及异步响应身份；保存后新增草稿不能被旧保存覆盖。
- 固定主页首签、项目签打开/关闭/溢出滚动和键盘导航；主页中的项目/连接入口保留。各页面接入前列出旧入口与新位置，不得因样板未画而删去功能。
- 失效/未应用/无权限等禁用依据，不把外观变化当作解除限制。
- 统计总体与真实失败证据；零值、未采集、不可计算不能混淆。
- 当前语言、主题、键盘操作、页面缩放；中英文长文案均可操作。
- 请求/响应原文可检查；主配置/状态/统计不得回退为 JSON 主视图。
