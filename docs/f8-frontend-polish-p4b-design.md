# P4b：公共阅读、离线页面与共享契约预览

2026-11-12，基线 `6a8ea89e`，工作树 `f8-frontend-polish`。沿用已确认视觉方向，不使用 superpowers 技能。

| 入口 | 本批验收条件 | 保留边界 |
| --- | --- | --- |
| 公共查看器 App | 当前语言可辨；搜索无结果可读，清除回焦；固定工具与独立目录滚动；长表局部滚动 | fragment 密钥、重新授权下载、迟到响应、复制失败提示均沿用 |
| 公共离线 HTML | 中文/English 各有可达目录锚点，主文卡片；完整指纹与安全原文仍折叠 | 仍为无脚本、无外部资源、原 CSP、safe DTO 与输出容量上限 |
| DocumentPreview（桌面共享） | 指纹短显可展开，已知生命周期随语言，未知值原样；深浅主题与长表 | 草稿、冲突、原始 Schema/正文及身份完全不变 |
| API 文档 HTML | 默认中文、English 切换；固定搜索/目录、计数、锚点和复制保留；局部表格/代码滚动 | 只本地化固定标签和已知枚举，不翻译业务文本，不改 Markdown/代码片段生成 |
| 运行报告 HTML | 中文/English 固定标签、顶部常驻筛选；非 HTTP 失败以条目/状态/原因展示，完整身份默认折叠 | 逻辑/原始总体、失败事实、行号和清除框独立性不变 |
| 压测 HTML | 固定语言/搜索、独立目录滚动；筛选目录与结果一致，无结果可清除；统一阅读样式 | 时间、基线、精度、图表真实观测、统计和脱敏均不改 |

验证顺序：先新增上述行为的必要测试，再集中实现；运行上述入口的具名测试及必要构建；通过真实组件/真实生成文件的本机 HTTP 浏览器样例核查中英、窄宽、短高、长内容与交互；最终由原审查者做本批一次有界独审。证据和失败原记录分别保存，不从 DOM 或构建推定视觉通过。无本地全量、Java 全套、完整 CI；无本轮合并/推送。
