## 2. 第一批　在线协作保存与显式应用远端更新

### 技术详细设计

1. **保存输入。** 点击保存时冻结编辑基线、实际改动和已有引用检查所需的依赖，绑定连接、账号、工作区、服务端项目 ID、契约项目 UUID 和目标定位。接口使用完整模块与文件夹路径。用例使用所属接口、用例 ID 和范围，删除也携带同样的定位和基线。新工作流在本次操作开始时固定 ID。服务端项目版本和编辑基线各自记录，收到新版本不会自动抬高旧草稿的基线。
2. **业务比对。** 在桌面主进程读取当前授权下的最新项目，使用 Core 解析并验证。针对明确支持的字段或对象做三方比对。双方同值可收束，独立变更保留两边。验证实际受影响的引用和默认请求继承，避免把「接口参数已改、用例仍继承旧请求」视为安全。同一接口的不同用例分别核对，合并后的用例索引由 Core 重新生成。目标被删、移位后身份无法核对、依赖或字段无法比较时保留草稿。首次覆盖正式接口保存、工作流创建、用例新增和编辑。涉及删除或改范围的既有用例保存按实际提交集合核对。
3. **生成与提交增量。** 对同一份最新业务快照运行标准编码，比较重放操作前后，提取实际更改的文件及显式删除。与整份服务器原文的比较只用于确认权限与结果，避免把无关的序列化差异写回。用重放时的项目版本提交，服务端保持最终 CAS、ACL、审计和资产校验。仅收到明确的版本竞争才重新读取后评估是否再次提交。计划默认最多补试一次，确切期限与可配置参数在开工核对现有网络配置后确定。权限、身份、内容和配额拒绝原样收束。
4. **提交结果未知。** 超时、连接断开或回执无法解码后，使用本次已固定的身份和预期业务变更重新读取。只有能核实目标状态已包含完整提交时，才结束为已保存或已收束。无法证实时保留本次提交身份和草稿，展示「保存结果待核对」，提供只读核对入口。挂起时的后续输入继续留在编辑器，核对使用已提交快照，避免重复创建。现有资产接口没有按本次操作查询的权威回执，不能以 HTTP 重发替代核对。
5. **界面已应用版本。** 分别保存已观察快照、界面已应用快照、草稿编辑基线。后台读取成功只更新待应用状态。保存成功只更新当前目标与其必要派生内容，其他成员的目录可见变化继续待应用。点击「查看」按资产列出新增、修改、删除。点「应用更新」使用用户预览的那一版，保留仍存在的签、选中项及滚动位置，发现更晚的版本继续单独提示。业务内容相同或可见差异撤回时清除提示。权限撤回按现有授权清理处理。
6. **读取时机与执行。** 项目首次打开读最新，保存前校验最新版。对同一项目切回、窗口回前台、重连合并重复检查。先测试现有 `GET /assets` 的正文与时机限制，按需决定是否加受同一授权保护的轻量版本查询。运行使用用户已确认的完整服务器版本。若界面只更新了自己刚保存的资产并保留其他远端改动待应用，仍以最近确认的完整版本作为执行前提。现有服务只能从当前版本建立新快照，核对不符时引导查看更新。已有执行和定时计划继续使用其固定快照。数据集、环境、压测配置、外部规范同步及在线旧格式保留各自已有写入口，需回归它们与待应用状态的交互。

## 3. 第二批　本地多实例保存与跨项目更新提示

复用第一批的业务比对、草稿归属和变更摘要，在本地宿主接入磁盘读取与事务写入。以工作区实际目录和资产完整路径区分不同项目与物理复制目录。保存时在已校验的最新磁盘快照重放指定操作，提交实际受影响的文件。保留最后的版本校验、写锁及日志。工作区共享变量、继承和引用有实际影响时按依赖冲突处理。

将磁盘发现的新版本与界面已应用版本分开。回前台、保存和主动刷新分别承担检查、提交与应用。发现乙保存项目 B 时，在甲的工作区入口给出「B 项目有更新 · 查看」。甲一次保存 A 后，只确认 A 的已提交内容，B 持续待应用。重点防止保存后的内存树请求顺带显示 B。确有冲突时复用当前的草稿保留与明确恢复流程，物理根改变、读中不稳定及任务占用继续走已有保护。

| 任务 | 前置 | 验收 |
| --- | --- | --- |
| LO-T1 接入本地保存 | 在线批业务规则已验收 | LO-01 双实例共用同一目录。乙保存 B 后甲一次保存 A，磁盘同时保留两笔改动。LO-02 共享依赖或同资产改动阻止写回并保留草稿。 |
| LO-T2 更新提示与应用 | LO-T1 的保存回执 | LO-03 甲留在 A 时只提示 B，目录、展开、滚动和当前输入保留。保存 A 后提示仍在，主动应用后才显示 B 的增删变化。 |
| LO-T3 生命周期和并发 | LO-T1、LO-T2 | LO-04 断开或替换物理根、同 ID 复制目录、晚到回执及读取后再次写入。旧上下文按实际根归属，最后 CAS 仍拒绝过期写入。 |
| LO-T4 独审和实包 | LO-T1～LO-T3 | LO-05 回归显式磁盘刷新、分步环境保存、冲突草稿、同配置启动复用及第一批在线入口。 |
