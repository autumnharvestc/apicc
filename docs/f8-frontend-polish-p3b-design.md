# F8 P3b：压测报告展示整理

2026-11-08，在 P1/P2/P3a 已提交的 `ac800736` 上继续。仅修改 StressReportView、StressTrendView 及中英文文案；生命周期实际内嵌于 StressReportView，不存在独立 StressLifecycleView。运行器、Core、基线固定选择、导出和 AI 身份传递不改。

## 界面与验收

1. 结论、目标、时间和指纹形成报告头；逻辑迭代与正式请求分成两块，完整性、失败和生命周期总体说明仍直接可读。容量、精度、负载发生器形成独立小节，不重算统计。
2. 节点现有斜杠计数虽在表头有组合说明，仍需横向对照。改成访问、通过、失败、中止、跳过及请求合格完成/失败的独立列；工作流与节点业务 ID 原样，聚合桶使用本地化“其他节点”。宽表局部滚动。
3. 生命周期用角色、VU、状态、耗时和失败类型表格；毫秒显示两位精度，原值悬停可查。失败/阈值继续保留原事实，阈值的实际值、要求值与说明分列。空记录明确说明，不伪造零值。
4. 旧版失败证据去除硬编码中文和固定 20 条的断言，显示本报告实际保留条数；未采集与已采集但无保留证据分开。旧安全策略用中文/英文标签，未知策略码和来源原文保留；loopback 未采集不再显示为 false，RSS 明确 MiB 单位。只改变展示。
5. 趋势沿用原始点、分段与坐标计算；样式使用已有主题变量。0/1 桶、缺口、时钟不对齐、阶段来源业务 ID 全部保留。阶段请求合格完成与失败分列。

## 验证和交付

- 新增真实类型的非空节点、生命周期、旧版安全/证据及缺测测试，先运行反例再改产品。
- 复用 stressWorkbench 的报告相关用例（逻辑/请求/完整性、预算、精度、阈值、来源阶段、零/单桶、生命周期、基线固定）及 components 的旧报告/历史调用方，不跑全量。
- Vue 类型检查、渲染构建；实际组件中文浅色、英文深色、窄视口集中验收。仅合成数据、无真实 IPC/后端执行，原生验收留 P5。
- 冻结后由既有审查者一次定向独审，记录每项证据与限制；通过后及时提交，不自行合并/推送。
